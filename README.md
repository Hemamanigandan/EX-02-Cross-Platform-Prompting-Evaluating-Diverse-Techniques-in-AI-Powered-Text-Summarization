# EX-02- Cross-Platform Prompting: Evaluating Diverse Prompt Engineering Techniques in AI-Powered Applications

## AIM
To evaluate and compare the effectiveness of prompting types across different AI platforms (e.g., ChatGPT, Gemini, Claude, Copilot) in a specific task: Eg. text summarization, Project Report generation, Paper writing...

## Scenario:
Example for Text Summarization - You are part of a content curation team for an educational platform that delivers quick summaries of research papers to undergraduate students. Your task is to summarize a 500-word technical article on "The Basics of Blockchain Technology" using multiple AI platforms and prompting strategies.

Your goal is to determine which combination of prompting technique + platform provides the best summary in terms of:

Accuracy

Coherence

Simplicity

Speed

User experience
